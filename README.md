# Friendship Test 🤝

A simple, interactive web app to test how well you know your friends!

## About

This is a basic web application where people can answer questions about their friends to see how well they really know them. Perfect for sharing with a few friends to have fun and strengthen connections.

## How to Use

1. **Open the app**: Simply open `index.html` in any web browser
2. **Share with friends**: Send the file to your friends or host it on any web server
3. **Take the test**: Answer 10 questions about your friend
4. **See your score**: Get instant feedback on how well you know your friend!

## Features

- 10 friendship-related questions
- Interactive and user-friendly interface
- Instant score calculation
- Responsive design that works on all devices
- No installation or setup required
- Completely self-contained (no external dependencies)

## Hosting Options

### Local Use
- Just open `index.html` in your browser

### GitHub Pages
1. Go to your repository Settings
2. Navigate to Pages section
3. Select the branch and save
4. Your app will be available at `https://[username].github.io/friendshiptest/`

### Other Options
- Upload to any web hosting service
- Share the HTML file directly via email or messaging apps

## Customization

You can easily customize the questions by editing the `questions` array in the JavaScript section of `index.html`. Each question has:
- `question`: The question text
- `options`: An array of 4 possible answers
- `correct`: The index (0-3) of the correct answer

Enjoy testing your friendships! 🎉
